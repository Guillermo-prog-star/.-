# Justificación

La justificación que se puede sostener con el repositorio está en la sección 5 del PT-PP-01 y se resume así:

Integrity Family trata el acompañamiento como un proceso de hasta 36 meses y no como una lista de tareas (`docs/vision.md`). La familia acepta el plan (`V111`, ADR-019). El protocolo ante un riesgo vital lo confirma una persona (`V98`). Compartir datos con una institución exige un consentimiento revocable (`V104`). Las hipótesis de identidad, pausa y recuperación se registran aparte del estado que el sistema sobrescribe (`V106`, ADR-004).
